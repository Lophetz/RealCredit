# RealCredit - 个人财务管理系统

RealCredit 是一个由 **Yuqiu** 设计开发的现代化个人记账与财务管理应用。它采用轻量级技术栈，提供流畅的“类 Notion”看板体验。

## ✨ 核心特性

### 📅 多视图看板
- **Daily (每日)**: 横向无限滚动的日期列，直观查看每一天的收支，支持“类 Notion”直接编辑。
- **Monthly (每月)**: 宏观视角的月度报表，自动汇总分类支出与收入。
- **Calendar (日历)**: 经典日历视图，快速概览全月每日盈亏。

### 💸 智能费用管理
- **摊销/分期 (Amortization)**: 支持将大额支出（如房租、保险、年费）按月或按天自动分摊到未来，真实反映每日财务压力。
- **收入管理**: 完整支持收入记录与分摊，绿色显示收入，红色显示支出。
- **预算控制**: 顶部实时显示月度预算进度条，助你掌控消费。
- **灵活策略**: 支持跳过周末（如工作日餐费）等高级分摊逻辑。

### 📥 智能导入
- **微信/支付宝账单**: 支持直接拖拽上传 Excel/CSV 账单文件。
- **自动分类**: 支持自定义关键词规则（如 "肯德基" -> "餐饮"），导入时自动归类。

## 📦 快速开始 (Windows Exe版)

这是最简单的使用方式，适合所有用户：

1. **下载**: 获取最新的 `RealCredit.exe` 程序包。
2. **准备**: 将 exe 文件放置在一个独立的文件夹中（例如 `D:\RealCredit`）。
   > *注意：程序运行会生成数据库文件，请保持文件夹整洁。*
3. **运行**: 双击 `RealCredit.exe`。
   - 会出现一个黑色命令行窗口（请勿关闭）。
4. **使用**: 打开浏览器，访问 [http://127.0.0.1:8000](http://127.0.0.1:8000) 即可开始记账。

## 源码运行 (开发者)

如果你熟悉 Python 并希望进行二次开发：

### 环境要求
- Python 3.9+
- Git

### 安装与运行
```bash
# 1. 克隆项目
git clone https://github.com/Lophetz/RealCredit.git
cd RealCredit

# 2. 安装依赖
pip install -r requirements.txt

# 3. 启动服务
python main.py
# 或使用 uvicorn
uvicorn main:app --reload
```

## 📖 常用操作

- **记一笔**: 点击日期列下的 `+` 号，输入金额、描述并选择分类。
- **分期/摊销**: 在添加记录时，设置 `Duration` (例如 12 Months)，系统会自动将金额分摊到未来。
- **数据导入**: 点击顶部的 `Import`，支持微信与支付宝账单导出文件的直接解析。
- **数据备份**: 点击 `Dev` 按钮可查看和导出 JSON 数据；你的所有数据实际上存储在同目录下的 `simple_log.db` 文件中，请定期备份该文件。

## ⚠️ 注意事项

- **数据安全**: 数据保存在本地数据库 (`simple_log.db`)，请务必定期备份该文件，以免误删丢失。
- **单机应用**: 本程序设计为本地单机使用，建议不要在公网环境直接暴露端口。
